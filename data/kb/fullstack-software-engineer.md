# Full-Stack Software Engineer Career Guide (India Freshers)

## Role Overview
Full-Stack Software Engineers ship end-to-end user-facing features spanning browser UI, backend APIs, and relational/NoSQL databases. Startups and product teams across Bengaluru, Pune, Hyderabad, Gurugram, and remote companies actively hire full-stack freshers who can own features independently. Typical fresher compensation in India is INR 45,000 to 1,25,000/month (internships INR 20,000 to 45,000/month).

## Core Skills & Prerequisites
Core stack in India: TypeScript, JavaScript (ES6+), React or Next.js, Tailwind CSS, Node.js (Express/NestJS) or Python (FastAPI), PostgreSQL or MongoDB, REST APIs, Git, and responsive accessible HTML/CSS. Strong freshers also understand browser state management, authentication cookies/JWT, basic Docker, and automated frontend/backend testing (Jest, Playwright, pytest).

## 4-Week Learning Roadmap
- **Week 1 — Modern TypeScript & React Fundamentals:** Solidify async/await, TypeScript generics/narrowing, React hooks, state architecture, and accessible responsive layouts with Tailwind CSS. Deliverable: interactive responsive multi-page UI consuming a public API with clean loading and error states.
- **Week 2 — Next.js App Router & Backend API Integration:** Connect a Next.js + TypeScript frontend to a Postgres-backed REST API (Node.js or FastAPI) with validation, pagination, and optimistic UI updates. Deliverable: full CRUD + search web app with real database persistence.
- **Week 3 — Auth, Performance & Testing:** Add authentication, form validation, keyboard accessibility, skeleton loaders, Core Web Vitals checks, and end-to-end tests with Playwright. Deliverable: Lighthouse accessibility & performance score above 90 plus passing E2E tests.
- **Week 4 — Production Polish & Deployment:** Deploy frontend (Vercel/Render) and backend (Render + Neon Postgres), wire GitHub Actions CI, and record a short demo GIF for your README.

## Free Courses & Resources
- **Full Stack Open — University of Helsinki** (https://fullstackopen.com/en/): Gold-standard free university course covering React, TypeScript, Node, GraphQL, testing, and Docker.
- **The Odin Project** (https://www.theodinproject.com): Project-driven web development curriculum.
- **Next.js Learn** (https://nextjs.org/learn): Official interactive App Router tutorial with Postgres.
- **JavaScript.info** (https://javascript.info): Deep reference for JS internals (event loop, closures, promises).
- **Web.dev Learn Accessibility & Performance** (https://web.dev/learn): Practical browser fundamentals.

## Portfolio Projects & Interview Prep
Build one genuinely useful, deployed app (not a clone tutorial) — e.g., a collaborative study planner, personal finance tracker with CSV import, or AI-powered interview prep tool. Prepare for JS event loop questions, React re-rendering & hooks pitfalls, SQL joins, REST vs GraphQL, CORS/XSS/CSRF security basics, and medium-level DSA problems.

## Adjacent Roles & Trade-Offs
- **Backend Engineer:** Deeper focus on databases, concurrency, and distributed systems without CSS/browser quirks.
- **Frontend Engineer:** Specializes in design systems, animations, accessibility, and complex client state.
- **QA Automation / SDET:** Leverages TypeScript + Playwright skills to build test infrastructure with less UI design pressure.
